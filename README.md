### Home work №9 for Hillel Front-end Pro course

Ви створюєте систему учасників такого собі Секретного клубу. Кожен учасник має публічне ім'я і таємний ID, за яким його впізнають на зборах. Двох людей з однаковими іменами може бути скільки завгодно, але таємний ID у кожного, унікальний, і не існує способу підробити його чи скопіювати.

Це саме те, для чого призначений тип Symbol. Ми побудуємо систему, покажемо її переваги, і спробуємо зламати, якщо вийде.
